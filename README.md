# Predicții Fotbal — Android test app

Private test application for creating and tracking football predictions.

Main features:
- local administrator login
- upcoming fixtures from TheSportsDB free API with offline demo fallback
- 1/X/2, double chance, totals, BTTS and exact-score markets
- local prediction publishing
- automatic result refresh for API-backed matches
- statistics and manual status management

Test admin credentials are shown inside the app login screen.
